# Резюме — страница на GitHub Pages

Одностраничное резюме на чистом HTML/CSS/JS (без сборки и зависимостей).
Цвета: фиолетовый `#800080`, белый, серый, чёрный.

## Структура файлов

```
resume-site/
├─ index.html          ← вся структура и текст резюме
├─ style.css           ← стили и цветовая палитра
├─ script.js           ← меню, прогресс-бар, галереи фото/дипломов
├─ assets/
│  ├─ photos/          ← сюда кладите фото с занятий / проектов (пункт 4)
│  ├─ certificates/    ← сюда кладите сканы дипломов и сертификатов (пункт 7)
│  └─ diplomas/        ← (по желанию) отдельно для дипломов об образовании
└─ README.md
```

## 1. Как отредактировать содержимое

Откройте `index.html` — все тексты идут по порядку разделов (1–9 из вашего
списка). Замените:

- имя, должность и контакты в блоке `<header class="hero">`
- текст «о себе», навыки, опыт, образование, проекты, сертификаты, языки —
  в соответствующих `<section>` с id `about`, `skills`, `experience`,
  `education`, `projects`, `certificates`, `languages`, `extra`.

Ссылки на проекты (пункт 6) — обычные `<a href="...">` внутри
`.project-card`, просто подставьте свои GitHub-репозитории.

## 2. Как добавить фото и дипломы (пункты 4 и 7)

1. Положите изображения в `assets/photos/` (опыт) или
   `assets/certificates/` (сертификаты).
2. В `script.js` найдите `GALLERY_CONFIG` и добавьте путь в массив
   `items`, например:
   ```js
   items: [
     { src: 'assets/photos/lesson-1.jpg', alt: 'Занятие по робототехнике' },
   ],
   ```
3. Сохраните и закоммитьте — фото появятся у всех, кто откроет сайт.

Обе галереи — горизонтальные, с прокруткой (`.gallery-scroll`), уже
поддерживают любое количество изображений.

**Клик по любому фото открывает его крупно** (лайтбокс на весь экран).
Закрыть — крестиком, кликом по тёмному фону или клавишей Esc.

## 3. Кнопка «Скачать PDF»

На странице есть кнопка «Скачать PDF» (рядом с контактами). Она вызывает
стандартную печать браузера — посетитель выбирает «Сохранить как PDF» в
диалоге печати. Это не требует сторонних библиотек и работает офлайн.

Для печати автоматически:
- скрываются боковое меню, прогресс-бар и лайтбокс;
- горизонтальные галереи (пункты 4 и 7) разворачиваются в сетку, чтобы
  **все** фотографии попали в документ, а не только видимая на экране часть.

Так как фото добавляются через `assets/` и `items` в `script.js`
(см. пункт 2 выше), они являются частью самой страницы — значит, попадут
в PDF у **любого** посетителя сайта.

## 4. Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `resume`
   (или `username.github.io`, если хотите резюме на корневом домене).
2. Загрузите в него все файлы из этой папки (`index.html`, `style.css`,
   `script.js`, папку `assets/`), сохранив структуру.

   Через git:
   ```bash
   git init
   git add .
   git commit -m "Резюме"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/resume.git
   git push -u origin main
   ```

3. На GitHub откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
5. Нажмите **Save**. Через 1–2 минуты сайт будет доступен по адресу:
   - `https://<ваш-логин>.github.io/resume/` — если репозиторий называется `resume`
   - `https://<ваш-логин>.github.io/` — если репозиторий назван `<ваш-логин>.github.io`

## 5. Проверка перед публикацией

- Замените все `username`, `example.com`, телефон и placeholder-тексты на свои.
- Проверьте, что все ссылки на проекты (пункт 6) рабочие.
- Откройте страницу на телефоне (или сузьте окно браузера) — меню уходит
  в бургер, галереи листаются пальцем.
